# Proposed design only
One query, two fixed selection pins, nine remote-result classes, four distinct epoch owners, at most one external epoch change, and a two-tick deadline. Native/Notion projection/owned supporting-file candidates may be admitted. Foreign-source/disabled/unmapped/wrong-workspace and AI response types are rejected independently. Full identity decoding, Notion indexing completeness, permissions TOCTOU outside known evidence, response schema/Unicode, pagination implementation, multiple result batches, actual catalog/network/browser/code and refinement are not proved. Local timeout/tick/preflight are weakly fair; a remote response is not assumed. The source epoch abstracts new current scope/Enabled/permission evidence; this proves rejection after an observed change, not impossible instantaneous awareness of an external revocation. The metadata epoch abstracts a query cursor/catalog binding invalidation. Queries only dispatch after the allowed source/connection is resolved. Empty results never establish exhaustive absence; no search transition changes root/Requires pins. Remote matching can include titles, so no content-only or exact-byte-match claim is made.

Independent review corrections: v1 gated positive snippets but not stale empty/error/rejection diagnostics; v2 checks the current publication ticket for every remote-derived status too. v1 represented routing only as a precondition; v2 records the actual dispatched bound/other connection independently. New negative configurations exercise both guards. These remain design-level abstractions of exact identity and context ownership.

Deadline review correction: the current-ticket predicate now includes tick < 2, independently of whether Timeout has already been scheduled. It guards dispatch, positive matches and all remote-derived statuses. The expired-ticket configuration deliberately skips only that deadline component across those three publication boundaries; its complete expected broken set is declared before execution. v3 changes no actual product code.
