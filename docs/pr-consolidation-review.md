# 单一交付 PR 的差异处置

本记录对应 AH-1048。CLI 只使用 PR #10，Broker 只使用其 PR #12；二者直接面向 `main`。关闭旧 PR 不代表其中每个非祖先提交已合入，也不授予发布或日用切换权限。

## CLI 分叉

旧 `05ccfc762c9dc9c405915a6d3be40eec822e267e` 的日常指引改进已按当前协议重做，而非整体回灌。包内三个 builtin 说明当前四表、公开维护与来源入口；删除过渡叙事、旧来源订阅路线及 JSON 的“兼容默认”说法。`packages/cli/test/builtin-guidance.test.ts` 检查这些正文、相对资源是否随包完整提供、已知失败与原操作恢复边界。

旧测试一概禁止 `ctl operation resume` 的条件不再适用。当前 shared apply 的原父操作具有经过验证的显式续办协议：仅原 Store 能证明未派发尾部；未知写入不重发；独立审阅只允许把已知失败关闭为 partial，不能变成原写成功。本次测试保留这条有效入口。

## 新增原生 reference 的执行边界

页面 ID 由真实创建确认。一次 `apply` 包含尚未分配页面的新 reference 及指向它的正文时，`SHARED_NATIVE_REFERENCE_UNBOUND` 必须在写前拒绝。公开支持的路径是添加 reference、重新读取固定版本、再提交链接及正文变更。已存在的文件仍可作为同一个父操作联合编辑；批次不具备原子回滚语义。

安装版渐进维护测试同时保留零写反例和两步成功流程。安装版 Pi 测试通过公开安装 CLI 先建立 reference 基线，再让 Pi 自行读取新 pin、编辑主文和两个已有 reference、核对原操作并消费结果。夹具准备写入单独保存在 `fixture-stage.json`，不得宣称是模型自主完成，也不向模型偷偷提供预期正文。

单次新页面 late binding 不是本批尚未完成的交付项，不为它增设父操作版本或恢复系统。这里采纳可解释的现有公开路径；它没有被改名为单次原子操作。

## 独立扫描提案

两仓原 Promptfoo PR #1 的新第三方扫描工作流不并入本次功能交付。该提案涉及另外的外部 action、权限与结果发布面；保留原提案及来源分支，不把它当作已启用的安全保障。本批继续使用仓库已有检查与限定范围的真实执行证据。

Broker 非祖先提交的逐组决定见该仓库同名文档。以上均是当前选择，不再通过新 PR 栈或未定的收尾阶段延长本批。
